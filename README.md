#  GamerVerse - Tu Portal de Videojuegos

Un sitio web moderno, responsivo y optimizado con temática *gaming* en modo oscuro. Este proyecto ha sido estructurado utilizando buenas prácticas de desarrollo web front-end mediante el uso de HTML5 semántico y CSS3 avanzado.

---

##  Objetivo del Proyecto

El objetivo principal de este proyecto es diseñar y maquetar una interfaz web interactiva, atractiva y totalmente responsiva orientada a la comunidad de videojuegos. 

Con este desarrollo se busca:
* **Ofrecer una experiencia de usuario (UX) inmersiva:** Mediante una paleta de colores oscura con acentos neón y morados, ideal para el público gamer.
* **Asegurar la adaptabilidad:** Implementar un diseño fluido usando **CSS Grid** y **Flexbox** para garantizar que la página se visualice correctamente en smartphones, tabletas y computadoras de escritorio.
* **Optimizar el rendimiento:** Construir el sitio utilizando únicamente código nativo (HTML y CSS) sin depender de librerías o frameworks pesados, logrando una carga instantánea.

## Flujo de Trabajo Usado

El equipo adoptó la metodología de trabajo **GitFlow simplificado** para mantener un desarrollo ordenado, colaborativo y libre de pérdida de código:

1.  **Planificación Inicial:** Creación del repositorio público en GitHub y sincronización con los entornos locales de cada integrante.
2.  **Estrategia de Ramas (Branching):**
    * `master`: Rama principal que contiene únicamente código estable y listo para producción.
    * `dev`: Rama de desarrollo donde se integró la estructura base y los componentes HTML5.
    * `diseno`: Rama destinada exclusivamente al diseño de estilos CSS, animaciones y comportamiento responsivo.
3.  **Gestión de Commits:** Se utilizó un estándar descriptivo para el historial de cambios (por ejemplo, `feat:` para nuevas características, `style:` para diseño y `fix:` para resolución de errores).
4.  **Revisión de Código (Pull Requests):** Los cambios realizados en las ramas de desarrollo no se fusionaron directamente; se enviaron solicitudes de extracción (*Pull Requests*) en GitHub para ser revisadas y aprobadas por el Líder de Proyecto.
5.  **Simulación y Resolución de Conflictos:** Se manejaron conflictos de manera real en las líneas del archivo principal (`index.html`) al intentar fusionar cambios simultáneos, resolviéndolos manualmente mediante editores de código para garantizar la integridad de la aplicación.
